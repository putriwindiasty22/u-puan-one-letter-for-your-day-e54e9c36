# One Letter for Your Day

Entry for the [One Letter for Your Day](https://make.fun/c/u-puan-one-letter-for-your-day-e54e9c36) bounty on [make.fun](https://make.fun).

## The entry

```
D
```

One letter, and nothing else — standing for the word that describes the day: **doomscrolling**.

Woke up meaning to check one thing, and surfaced hours later from an endless scroll — sore thumb, dead battery, zero memories of what was even on the screen. The most honest one-letter diary of a modern day: vivid, funny, and true, and D is the only initial it could possibly wear.

## How it works

Run the entrypoint with Node 22.18+ (Node runs the TypeScript directly, no build step):

```sh
node main.ts
```

It writes exactly one character, `D`, to `/output/entry.txt`. Before writing, it validates that the letter matches the gate — a single character A–Z — and refuses anything else.
